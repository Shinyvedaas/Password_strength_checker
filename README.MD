## Objective

The objective of this project is to build a beginner-friendly password strength checker using Python. The tool analyzes passwords based on length, complexity, common password usage, repeated characters, and predictable patterns all using a password list file. It helps demonstrate how weak passwords can be identified and how users can improve password security.

This project was created as part of a cybersecurity portfolio to demonstrate Python scripting, security automation, file handling, and basic password policy analysis.
